## Featured Work

### Qemer Market — E-Commerce Platform

A mobile-first e-commerce catalog built for a real business. Customers can browse products, search the catalog, manage a cart, and place orders through Telegram or WhatsApp without requiring an online checkout.

The platform also includes an **admin dashboard**, product management, image uploads, authentication, API integration, and production deployment.

**Built with:** React, TypeScript, Vite, Tailwind CSS, React Router, Framer Motion, Node.js, Express, MongoDB Atlas, Mongoose, JWT, Cloudinary

🔗 **Repository:** https://github.com/babaty73/Qemer-shopping

### ASTU Bootcamp Management System

A role-based management system designed for an ASTU bootcamp. The system brings together authentication, students, mentors, attendance, assignments, submissions, grading, leaderboards, announcements, notifications, calendars, dashboards, reports, badges, and learning resources.

I work on the system as part of a collaborative development team, contributing to the implementation and integration of core modules and workflows.

**Built with:** React, TypeScript/JavaScript, Vite, React Router, Tailwind CSS, React Hook Form, Axios, Node.js, Express, MongoDB, Mongoose, JWT

🔗 **Repository:** https://github.com/babaty73/ASTUMSJ-Bootcamp-dev

### Bloom-Care — Medicine Availability Platform

A healthcare-focused web application designed to help people in Ethiopia find medicines available at nearby pharmacies before making a trip.

The platform is designed around medicine search, pharmacy availability, price comparison, last-updated information, and location-based pharmacy discovery.

**Built with:** React, TypeScript, Tailwind CSS, React Router, Framer Motion, Node.js, Express, MongoDB, JWT, Google Maps, Cloudinary

🔗 **Repository:** https://github.com/babaty73/Bloom-care
